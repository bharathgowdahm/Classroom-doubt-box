Silent Classroom Doubt Box
Ask fearlessly. Learn endlessly. — ಸಂದೇಹವಿಲ್ಲದೆ ಕೇಳಿ, ನಿರ್ಭಯವಾಗಿ ಕಲಿಯಿರಿ

An anonymous doubt-clearing platform for students who hesitate to ask in class. Drop doubts anonymously, get instant AI hints, join live mentor sessions, and explore curated learning resources.

✨ Features
Anonymous Doubt Box – ask without revealing identity, toggle on/off
AI-Powered Search – instant plain-English explanations (recursion, OOP, DBMS, OS, Git, CSS & more)
Live Sessions – upcoming + LIVE doubt-clearing rooms with agenda and invite links
Curated Resources – direct links to GeeksforGeeks, MDN, Stack Overflow, NPTEL, Khan Academy
Live Activity Feed – real-time community pulse
Premium Dark UI – glassmorphism, responsive, mobile-first
🛠️ Tech Stack
Web: React, TypeScript, Tailwind CSS, Vite, Lucide Icons
Java: Java 17, Spring Boot 3, Thymeleaf, Maven
